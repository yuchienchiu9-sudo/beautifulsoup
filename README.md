# BeautifulSoup – Course Extensions

This repository is based on the original BeautifulSoup 4 library and is used
for SWE 244P course milestones.

- Core library code lives under `bs4/`.
- Course-specific applications live under `apps/`:
  - `apps/m2`: Milestone 2 apps and README
  - `apps/m3`: Milestone 3 apps and README
  - `apps/m4`: Milestone 4 apps and README (iterable soup)

For details about each milestone (how to run tasks, demo commands, and API
design notes), please see the corresponding `M*-README.md` files in each
`apps/m*` directory.
